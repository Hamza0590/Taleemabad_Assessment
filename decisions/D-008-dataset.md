# D-008 — Dataset: use a public dataset instead of collecting our own
Date: 2026-11-25
Status: DECIDED (user); dataset choice PROPOSED until we inspect the files

## User's decision
Collect data online if possible. In the write-up, explain that real board scripts are not public,
and collecting our own in one day was not possible, so we tested on a public dataset.
Scope (user): not only Physics. Any paper written in English, as long as we have its answer key.

## Search done (2026-11-25) — what exists
Researchers themselves say end-to-end handwritten grading datasets (images in, scores out) are
rare because scripts are privacy-sensitive (arXiv 2601.00730). Candidates found:
1. Mendeley "A Dataset of Digitized Student Examination Papers, Answer Keys, and Manual
   Evaluations for Automated Grading Research" (DOI 10.17632/sf3kvjwknt.1, CC BY 4.0, Apr 2026).
   50 real handwritten university Data Science exams (Anna University, India), in English.
   20 MCQs (1 mark) + 15 short answers (2 marks) = 50 marks. Includes the question paper,
   answer key, the 50 UNMARKED scripts, the SAME 50 scripts MARKED by the teacher (annotations),
   and a CSV of per-question teacher marks.
   -> Has everything our idea needs: script, key, the examiner's marks on the page, and an award list.
2. FERMAT (AI4Bharat, ACL 2025): 2,200+ handwritten maths solutions with deliberately planted
   errors. No examiner marks. Useful only to stress-test the AI second reader.
3. HF chandrabhuma/AnswerScripts: 5,914 phone-scanned answer pages, 21 students. No keys or marks. REJECTED.
4. HF JunaidMB GCSE crops: 78 handwritten answer crops plus text. OCR only, no marks. REJECTED.
5. Indonesian grade-4 dataset (arXiv 2506.04822): no public download found. REJECTED.
6. Zenodo OBE dataset (485 scanned answers with rubrics): "available upon reasonable request". REJECTED for time.
7. EWCCE (Mendeley): 200 handwritten English essays with IELTS bands. Holistic essay scoring
   doesn't match per-question marking. REJECTED.

## Choice
Primary: #1 (Mendeley sf3kvjwknt). Optional: #2 for an extra VLM stress test.

## Assumptions and limitations to state openly
- We treat the teacher's marks as the "correct" baseline. The teacher may have made mistakes too.
- It is a university exam, not a Pakistani board exam. The format (handwritten, English, MCQ +
  short answers, answer key) is close to board papers, but it's not the same population.
- 50 scripts is small, so we report confidence intervals.
- Marking errors are PLANTED by us, with a random plan generated by code before development (see P3).
- 2-mark short answers leave little room for "a bit under-credited", so planted errors there
  are at least 1 full mark.
